# Security Policy

Do not open a public issue containing credentials, provider account data, private prompts, customer material, restricted outputs, exploit details, or personal information.

For a security or privacy report that cannot be public, follow the private route documented at https://github.com/mmjbds/mianzhang.org/blob/main/.github/SECURITY.md.

WisdomBench is a public research benchmark, not a production execution system or safety certification. Security reports should identify the affected public file or interface, version, impact, and the smallest safe reproduction that does not disclose sensitive material.
