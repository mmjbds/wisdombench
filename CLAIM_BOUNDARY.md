# Claim Boundary

WisdomBench is a longitudinal benchmark for measuring learning-from-failure behavior in language agents.

## Supported Claims

- The repository defines a small public schema for repeated-round evaluation.
- The scoring utility computes task-level and aggregate longitudinal metrics.
- The sample data can be reproduced locally without external APIs.
- The benchmark distinguishes first-attempt performance from later-round adaptation.

## Unsupported Claims

- It does not prove that any AI system has human-like wisdom.
- It does not certify deployment safety.
- It does not include private model API logs or paid-provider traces.
- It does not claim that more parameters alone solve failure learning.

## Correct Use

Use this repository to inspect the measurement protocol, run small examples, and submit reproduction reports or benchmark adapters.
