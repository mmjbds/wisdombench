# Wisdom Science 投稿预检表

日期：2026-05-04

## 目标

这份清单用于投稿、预印本发布、Zenodo 更新或对外路演前的最后口径检查。核心原则是：强主张必须有强证据；框架性主张可以大胆，但必须明确其边界、证据等级与后续验证路径。

## 一句话定位

Wisdom Science 不是把“聪明”换个名字，而是把 AI 评测从 first-round competence 推进到 after-experience improvement：失败之后是否更好、更稳、更能迁移。

## 审稿人可能攻击的问题

### 1. 这是不是又一个 benchmark？

回答口径：不是单一 benchmark。WisdomBench 和 WB-E 是测量层；Cognitive Immunity 是机制层；Second Scaling Law 是结构层；Representation Genesis 是表示法层；Evidence Gate 是证据治理层。它们共同构成“经验之后是否变好”的评测与工程体系。

### 2. WQ 只是 success rate 差值吗？

回答口径：WQ/EWQ 的最小形式确实包含跨轮表现差，但贡献不止差值。关键是固定 first-round intelligence 与 after-experience improvement 的分离、归一化、跨任务聚合、扰动/迁移/稳定性分解，以及 provenance gate。

### 3. 压缩、宏发现、程序库学习早就有人做了，贡献在哪里？

回答口径：承认已有工作。我们的贡献不是“压缩首创”，而是把 representation search 放进 Wisdom Science：同一系统必须同时追踪压缩收益、解包成本、迁移率、复用率、失败残差吸收和证据门。

### 3b. 视角接地是不是 active perception / symbol grounding 的旧瓶新酒？

回答口径：承认邻近方向。我们的贡献不是发现“多视角有用”，而是把 projection、viewpoint、hypothesis set、evidence cost、semantic context 和 counter-reflexive belief 统一登记为智慧系统的证据对象，并接入 P8/P9 的 failure/evidence gate。

### 4. 机器人证据是否足够？

回答口径：分层回答。已完成的真实具身证据只按已有 evidence gate 写；P9 当前新增的是 8-cell matched non-training recovery-adapter pilot，3/8 rescue、0 regression。它可以作为小型真实恢复证据，但不能写成 public SOTA leaderboard、训练策略或通用机器人自愈。需要更大 seed/task/policy coverage 的地方明确标为后续云端触发任务。

当前最硬的真实具身层包括 RVT-2 official supported 270、PerAct public checkpoint supported 270、Act3D/3D Diffuser official-evaluator strict sidecar 36、UnifoLM-VLA LIBERO supported 1,200，以及 self-trained lowdim 6,300 的规模证据。它们不能混写成 public VLA/SOTA 6,300。

### 4b. 全机体智能是不是生物学比喻？

回答口径：不是单纯比喻。每个器官层都对应工程 substrate、typical failure、evidence gate 和 wisdom metric。它借鉴生物/心理/社会系统，但论文主张是具身 AI 的工程验收框架，不是人体科学总论。

### 5. 为什么不直接宣称 6,300 public VLA/SOTA leaderboard？

回答口径：因为没有足够独立 public runnable checkpoint/factory 支撑时，不能把 self-trained lowdim 或 sidecar 结果写成 public VLA/SOTA full leaderboard。我们宁愿牺牲夸张标题，也保住证据可信度。

### 5b. 六模型 API panel 是否能补机器人证据？

回答口径：不能。它补的是 text-agent 侧低成本跨模型纵向证据，展示同一 evidence-gate philosophy 在 Claude/DeepSeek/Qwen 等端点上可执行。具身论文只把它作为 portfolio boundary，不把它写进 RLBench/LIBERO 成功率主张。

### 6. 这套东西是不是太大、太泛？

回答口径：总框架大，但每个层级都有可执行 artifact：claim registry、macro mining、compression study、leaderboard schema、failure atlas schema、P8/P9/Foundation PDF、evidence index。大框架必须落在可复现产物上。

### 7. 物理语言是不是空泛类比？

回答口径：不是。Physics/Engineering Core 把每个物理词落成测量对象：plasticity 是经验响应，homeostasis 是扰动阻尼，failure immunity 是重复失败衰减，wisdom efficiency 是单位成本增益。每个量都有失败条件和可执行 sanity check。

### 8. 工程上能不能验收？

回答口径：可以。强结果必须同时通过 metric、stability、provenance、cost、duplicate-cell gates。没有 raw logs、seeds、metadata、checkpoint/factory、hashes 的结果不能作为强证据。

## 当前版本结论

当前版本已经适合对外作为 Wisdom Science 研究包展示：它不是最终真理证明，而是一个有定义、有理论、有实验脚手架、有边界、有证据索引的研究纲领。后续真正能显著提高冲击力的不是继续改口号，而是新增真实 rollout、真实 public checkpoint/factory 和更大规模跨模型 API longitudinal panel。
