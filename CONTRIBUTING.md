# Contributing

We welcome reproducibility reports, bug reports, small benchmark tasks, documentation fixes, and minimal demos.

## Good Contributions

- A failing reproduction case with input and expected output.
- A clearer claim-boundary sentence.
- A new sample task with a scoring rubric.
- A verifier that catches a false claim.

## Not Accepted

- Private data.
- API keys or secrets.
- Live trading / deployment hooks.
- Claims that require undisclosed evidence.
